# ScamSim Backup Video Recording Protocol

To protect against live stage demo failures, network dropouts, or projector resolution glitches, maintain a verified backup video recording of the working application.

---

## 1. Recording Specifications

* **Maximum Duration**: Under 3 minutes (recommended: ~2:30–2:45).
* **Resolution**: 1920×1080 (1080p, 60fps or 30fps).
* **Audio**: Clear microphone voiceover adhering to [docs/DEMO_SCRIPT.md](DEMO_SCRIPT.md); no background music.
* **Format**: Standard `.mp4` (H.264 / AAC) with universal hardware acceleration compatibility.

---

## 2. Rehearsal & Production Checklist

- [ ] **Clean Browser Environment**:
  - Open an Incognito/Private browser window or clean Chrome profile.
  - Disable browser extension badges, notification popups, and bookmark bars.
  - Set default zoom to 100%.
- [ ] **Recording Coverage**:
  - [ ] 0:00–0:15: Landing Page problem statement and value prop.
  - [ ] 0:15–0:45: Launch Scenario A, highlight SIMULATION banners and pressure tactics.
  - [ ] 0:45–1:15: Take the impulsive choice, show simulated loss feedback and red flags.
  - [ ] 1:15–1:35: Restart scenario, take safe branch, advance cleanly.
  - [ ] 1:35–2:00: Results page, highlight score ring, timeline, and takeaways.
  - [ ] 2:00–2:20: Progress page, show updated skill competency bars and adaptive recommendation.
  - [ ] 2:20–2:45: Architecture diagram and Cloud Console / test suite evidence.
- [ ] **Verification & Redundancy**:
  - [ ] Play back full `.mp4` video locally from start to end; ensure audio and video remain synchronized.
  - [ ] File stored locally on primary presentation laptop.
  - [ ] File copied to secondary presentation device (USB drive, secondary laptop, or phone).
  - [ ] Direct file download link staged on Google Drive / cloud storage as tertiary backup.
